Server Routes (server/routes.ts) Documentation

Overview

The server/routes.ts file is responsible for setting up the HTTP server and defining the API routes and WebSocket communication for the SmartHaven backend. It uses Express for handling HTTP requests and ws for WebSocket connections.

The registerRoutes function initializes the HTTP server, sets up the WebSocket server on the /api/ws path, and defines various API endpoints for user authentication, device management, room management, route management, scene management, and logging.

WebSocket Communication (/api/ws)

The WebSocket server provides real-time communication capabilities. Clients can connect to /api/ws to receive updates and send control commands.

  • Connection: Upon successful connection, a connected message is sent to the client.
  • Message Handling: The server listens for incoming messages and handles different types, such as device_control.
  • Broadcasting: Updates (e.g., device status changes) are broadcast to all connected WebSocket clients.

API Routes

The following HTTP API routes are defined:

Authentication

  • POST /api/auth/login: Handles user login. Requires username and pin in the request body.
  • POST /api/auth/register: Handles new user registration. Requires username and pin in the request body.

Device Management

  • GET /api/devices: Retrieves all registered devices.
  • POST /api/devices: Adds a new device. Requires device details (name, route, type, pin) in the request body.
  • PUT /api/devices/:id: Updates an existing device by ID. Requires updated device data in the request body.
  • DELETE /api/devices/:id: Deletes a device by ID.

Room Management

  • GET /api/rooms: Retrieves all registered rooms.
  • POST /api/rooms: Adds a new room. Requires room details (name) in the request body.
  • PUT /api/rooms/:id: Updates an existing room by ID. Requires updated room data in the request body.
  • DELETE /api/rooms/:id: Deletes a room by ID.

Route Management

  • GET /api/routes: Retrieves all registered routes.
  • POST /api/routes: Adds a new route. Requires route details (name, path) in the request body.
  • PUT /api/routes/:id: Updates an existing route by ID. Requires updated route data in the request body.
  • DELETE /api/routes/:id: Deletes a route by ID.

Scene Management

  • GET /api/scenes: Retrieves all registered scenes.
  • POST /api/scenes: Adds a new scene. Requires scene details (name, actions) in the request body.
  • PUT /api/scenes/:id: Updates an existing scene by ID. Requires updated scene data in the request body.
  • DELETE /api/scenes/:id: Deletes a scene by ID.

Logging

  • GET /api/logs: Retrieves all logs.

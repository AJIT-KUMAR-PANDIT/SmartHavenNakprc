Server Storage (server/storage.ts) Documentation

Overview

The server/storage.ts file defines the data storage interface (IStorage) and provides an in-memory implementation (MemStorage) for the SmartHaven backend. This module is responsible for managing users, devices, routes, logs, and settings.

The IStorage interface outlines the required methods for any storage implementation, ensuring a consistent API for data access and manipulation. The MemStorage class provides a simple, non-persistent implementation using JavaScript Maps and arrays.

IStorage Interface

Defines the contract for data storage operations:

  • User Management: getUser, getUserByUsername, createUser
  • Device Management: getDeviceById, getAllDevices, addDevice, updateDevice, updateDeviceStatus, removeDevice
  • Route Management: getRouteById, getAllRoutes, addRoute, updateRoute, updateRouteAccess, removeRoute
  • Logs: addLog, getAllLogs, pruneOldLogs
  • Settings: saveSettings, getSettings, exportSettings, importSettings

MemStorage Class

An in-memory implementation of the IStorage interface. Data is stored in memory and is not persistent across server restarts. It includes methods for:

  • Initializing with default system routes.
  • Generating unique IDs for entities.
  • Implementing all methods defined in the IStorage interface using Maps and arrays.

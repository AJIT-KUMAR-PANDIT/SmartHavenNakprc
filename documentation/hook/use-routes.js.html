useRoutes Hook (hooks/use-routes.js) Documentation

Overview

The useRoutes hook (hooks/use-routes.js) is a custom React hook designed to manage the state and operations related to application routes. It provides functions for loading, creating, updating, and deleting routes, as well as recording route access.

State

  • routes: An array containing the list of routes.
  • isLoading: A boolean indicating whether routes are currently being loaded.
  • error: Stores any error that occurs during route operations.

Functions

  • loadRoutes(): Fetches all routes from the database and updates the routes state.
  • createRoute(routeData): Adds a new route to the database and updates the routes state.
  • editRoute(id, routeData): Updates an existing route in the database and updates the routes state.
  • deleteRoute(id): Removes a route from the database and updates the routes state.
  • recordAccess(route): Records an access event for a specific route.
  • getRouteByPath(path): Finds and returns a route object based on its path.

Dependencies

  • useState and useEffect from React.
  • Database interaction functions (addRoute, updateRoute, removeRoute, getAllRoutes, updateRouteAccess, addLog) from @/lib/db.

Usage

This hook is intended to be used in components or other hooks that need to interact with the application's routing data. It encapsulates the data fetching, state management, and error handling logic for routes.

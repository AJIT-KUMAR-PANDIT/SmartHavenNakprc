Alert Component (alert.tsx) Documentation

Overview

The Alert component (components/ui/alert.tsx) is a composite component built using class-variance-authority for styling variants. It provides a way to display important messages with different visual styles.

Usage

This component includes sub-components: Alert, AlertTitle, and AlertDescription. It uses the cn utility for class merging.

Dependencies

  • class-variance-authority: For defining and applying component variants.
  • cn utility function: For conditionally joining and merging CSS classes.

Props

  • variant (enum: 'default', 'destructive'): Defines the visual style of the alert.
  • Standard HTMLDivElement props for Alert.
  • Standard HTMLHeadingElement props for AlertTitle.
  • Standard HTMLParagraphElement props for AlertDescription.

Styling

Styling is managed using class-variance-authority and Tailwind CSS classes, with specific styles for the 'default' and 'destructive' variants.

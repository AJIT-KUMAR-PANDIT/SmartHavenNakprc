Sidebar Component (components/ui/sidebar.tsx) Documentation

Overview

The Sidebar component (components/ui/sidebar.tsx) provides a flexible and collapsible sidebar layout for the application. It includes support for different variants (sidebar, floating, inset) and collapsible behaviors (offcanvas, icon, none).

Usage

The component uses a context (`SidebarContext`) to manage its state (expanded/collapsed, open/closed for mobile) and provides a hook (`useSidebar`) to access this context. It also includes a keyboard shortcut (`Ctrl+B` or `Cmd+B`) to toggle the sidebar state.

Dependencies

  • @radix-ui/react-slot: Used for flexible component rendering.
  • class-variance-authority: For managing component variants.
  • lucide-react: Used for icons (e.g., PanelLeft).
  • useIsMobile hook: To determine the current device type.
  • cn utility function: For conditionally joining and merging CSS classes.
  • Button, Input, Separator, Sheet, Skeleton, Tooltip components: Other UI components used within the sidebar.

Props

  • side: Specifies the side of the screen the sidebar appears on ('left' or 'right').
  • variant: Defines the visual style and behavior ('sidebar', 'floating', or 'inset').
  • collapsible: Controls how the sidebar collapses ('offcanvas', 'icon', or 'none').
  • defaultOpen: Initial open state (for uncontrolled usage).
  • open: Controlled open state.
  • onOpenChange: Callback for when the open state changes.

Styling

Styling is applied using Tailwind CSS classes and the cn utility function, with support for different states (`data-state="expanded"` or `data-state="collapsed"`).

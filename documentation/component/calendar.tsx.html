Calendar Component (components/ui/calendar.tsx) Documentation

Overview

The Calendar component (components/ui/calendar.tsx) is a wrapper around the react-day-picker library, providing a styled and customizable date picker component.

Usage

This component is built on top of react-day-picker and applies custom styling using Tailwind CSS classes and the cn utility function. It exposes the props of react-day-picker, allowing for flexible configuration.

Dependencies

  • react-day-picker: Provides the core calendar functionality.
  • lucide-react: Used for navigation icons (ChevronLeft, ChevronRight).
  • cn utility function: Used for conditionally joining and merging CSS classes.
  • buttonVariants from @/components/ui/button: Used for styling the navigation buttons.

Styling

Extensive styling is applied via the classNames prop of react-day-picker, using Tailwind CSS classes to customize the appearance of different parts of the calendar, such as months, captions, navigation buttons, table, cells, and days.

Custom Components

The component replaces the default navigation icons of react-day-picker with icons from lucide-react using the components prop.

Select Component (client/src/components/ui/select.tsx) Documentation

Overview

The Select component is a custom implementation built on top of Radix UI's Select primitive. It provides a styled and accessible dropdown for selecting a value from a list of options.

Usage

This component wraps the core functionality of @radix-ui/react-select and applies custom styling using Tailwind CSS. It includes sub-components like SelectTrigger, SelectContent, SelectItem, etc., which correspond to the Radix UI primitives.

Dependencies

  • @radix-ui/react-select: Provides the core accessible select functionality.
  • lucide-react: Used for icons (e.g., ChevronDown, Check).
  • cn utility function: Used for conditionally joining and merging CSS classes.

Components

  • Select: The root component, wraps the entire select.
  • SelectGroup: Used to group related items in the dropdown.
  • SelectValue: Displays the currently selected value.
  • SelectTrigger: The button that opens the dropdown.
  • SelectContent: The container for the dropdown items.
  • SelectLabel: A label for a group of items.
  • SelectItem: Represents an individual selectable option.
  • SelectSeparator: A visual separator between items or groups.
  • SelectScrollUpButton, SelectScrollDownButton: Buttons for scrolling within the dropdown content if there are many items.

Styling

Styling is applied using Tailwind CSS classes, often combined with the cn utility function for conditional styling and merging.

App Guide Component (app-guide.jsx) Documentation

Overview

The App Guide component is likely used to provide users with a guided tour or tutorial of the application's features. It helps new users understand how to navigate and use the SmartHaven application effectively.

Props

  • steps (array of objects): An array defining the steps of the guide. Each object might contain properties like selector (CSS selector for the element to highlight), content (text or HTML content for the step), and position (position of the guide popover relative to the element).
  • isOpen (boolean): Controls whether the guide is currently active and visible.
  • onClose (function): A callback function executed when the guide is completed or closed by the user.

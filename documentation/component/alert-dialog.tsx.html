Alert Dialog Component (alert-dialog.tsx) Documentation

Overview

The AlertDialog component is used to display a modal dialog that requires user interaction, typically for confirmations or important messages. It blocks interaction with the rest of the application until the user dismisses it.

Props

  • isOpen (boolean): Controls whether the dialog is currently open or closed.
  • onClose (function): A callback function executed when the dialog is requested to be closed (e.g., by clicking outside or pressing Escape).
  • title (string): The title displayed at the top of the dialog.
  • description (string): The main content or message displayed within the dialog.
  • confirmText (string, optional): The text for the confirmation button (defaults to 'Confirm').
  • cancelText (string, optional): The text for the cancel button (defaults to 'Cancel').
  • onConfirm (function, optional): A callback function executed when the confirm button is clicked.
  • onCancel (function, optional): A callback function executed when the cancel button is clicked.

Basic Usage


import React, { useState } from 'react';
import AlertDialog from './AlertDialog';

const MyComponent = () => {
  const [isDialogOpen, setIsDialogOpen] = useState(false);

  const handleConfirm = () => {
    console.log('Confirmed!');
    setIsDialogOpen(false);
  };

  const handleCancel = () => {
    console.log('Cancelled!');
    setIsDialogOpen(false);
  };

  return (
    <>
      
       setIsDialogOpen(false)}
        title="Confirm Action"
        description="Are you sure you want to proceed with this action?"
        onConfirm={handleConfirm}
        onCancel={handleCancel}
      />
    
  );
};

export default MyComponent;

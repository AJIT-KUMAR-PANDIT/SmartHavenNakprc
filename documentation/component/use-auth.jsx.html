useAuth Hook and AuthProvider (hooks/use-auth.jsx) Documentation

Overview

The useAuth hook and its associated AuthProvider component provide a context-based solution for managing user authentication state throughout the client application. They handle user login, signup, logout, and persistence of the authenticated state using local storage.

AuthProvider Component

This component wraps the part of the application that needs access to authentication state and functions. It initializes the authentication state by checking local storage for a stored user session and provides the authentication context to its children.

State

  • currentUser (object | null): Stores the currently authenticated user object, or null if not authenticated.
  • isAuthenticated (boolean): Indicates whether a user is currently authenticated.
  • isLoading (boolean): Indicates if an authentication operation (login, signup, initial check) is in progress.
  • authError (string | null): Stores any error message related to authentication operations.

useAuth Hook

This hook provides access to the authentication state and functions provided by the AuthProvider. It should be used within a component that is a descendant of AuthProvider.

Returned Values

  • currentUser (object | null): The currently authenticated user.
  • isAuthenticated (boolean): Authentication status.
  • isLoading (boolean): Loading status of authentication operations.
  • authError (string | null): Authentication error message.
  • login (function): Asynchronous function to handle user login (async (username, pin) => boolean).
  • signup (function): Asynchronous function to handle user signup (async (username, pin) => boolean).
  • logout (function): Function to handle user logout.

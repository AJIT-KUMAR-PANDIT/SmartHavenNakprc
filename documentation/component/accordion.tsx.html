Accordion Component (accordion.tsx) Documentation

Overview

The Accordion component (components/ui/accordion.tsx) is built on top of the @radix-ui/react-accordion primitive. It provides a set of components for creating collapsible content sections.

Usage

This component includes the main Accordion root component and sub-components like AccordionItem, AccordionTrigger, and AccordionContent. It uses the cn utility for class merging and lucide-react for the collapse/expand icon.

Dependencies

  • @radix-ui/react-accordion: Provides the core accessible accordion functionality.
  • lucide-react: Used for the ChevronDown icon.
  • cn utility function: Used for conditionally joining and merging CSS classes.

Components

  • Accordion: The root component for the accordion.
  • AccordionItem: Wraps each individual collapsible section.
  • AccordionTrigger: The interactive element that toggles the content visibility.
  • AccordionContent: The collapsible content area.

Styling

Styling is applied using Tailwind CSS classes via the cn utility function. Animations for collapsing and expanding are handled using CSS transitions and Radix UI's data attributes (`data-state`).

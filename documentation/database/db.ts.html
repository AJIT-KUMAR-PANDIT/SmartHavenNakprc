Server Database Connection (server/db.ts) Documentation

Overview

The server/db.ts file is responsible for establishing and managing the database connection for the SmartHaven backend. It uses Drizzle ORM with the Neon serverless driver to connect to a PostgreSQL database.

Database Connection

This module configures and exports a database connection pool and a Drizzle ORM instance.

  • It uses the @neondatabase/serverless package for connecting to a Neon database.
  • It requires the DATABASE_URL environment variable to be set for the connection string. An error is thrown if this variable is missing.
  • A connection pool is created using @neondatabase/serverless.
  • Drizzle ORM is initialized with the connection pool and the shared database schema defined in @shared/schema.
  • The configured Drizzle ORM instance (db) and the connection pool (pool) are exported for use in other parts of the server.

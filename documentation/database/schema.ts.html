Database Schema (shared/schema.ts) Documentation

Overview

The shared/schema.ts file defines the database schema for the SmartHaven project using Drizzle ORM and Zod for type validation. It includes definitions for the main data models used across the client and server.

Data Models

The following data models are defined:

User

  • id (text): Primary key, unique identifier.
  • username (text): User's username, not null, unique.
  • pin (text): User's PIN, not null.
  • createdAt (timestamp): Timestamp of user creation, defaults to now.

Associated Zod schema: insertUserSchema for creating new users.

Device

  • id (string): Unique identifier.
  • name (string): Device name.
  • route (string): Associated route for communication.
  • type (string): Device type (e.g., light, sensor).
  • pin (number): Device PIN.
  • status (string): Current status (e.g., online, offline).
  • lastSeen (string | null): Timestamp of last seen activity.
  • value (number, optional): Current value for sensors.
  • unit (string, optional): Unit for sensor value.
  • brightness (number, optional): Brightness level for lights.
  • level (number, optional): Generic level for devices.

Route

  • id (string): Unique identifier.
  • route (string): Route path.
  • type (string): Route type (e.g., system, device).
  • action (string, optional): Description of the action.
  • method (string, optional): HTTP method (e.g., GET, POST).
  • lastAccessed (string | null): Timestamp of last access.
  • deviceStatus (string, optional): Associated device status.

Log

  • action (string): Type of action logged.
  • message (string): Log message details.
  • timestamp (string): Timestamp of the log entry.

Settings

An object containing various application settings, potentially including:

  • mqtt: MQTT connection settings.
  • notifications: Notification preferences.
  • theme: UI theme settings.
  • advanced: Advanced configuration options.

About Page (about.jsx) Documentation

Overview

This file (`about.jsx`) implements the About Us, Our Team, and Contact Us sections of the client application. It provides information about the company, its mission, values, team members, and contact details.

The component uses `useState` for managing the active tab and contact form data. It includes basic form validation and simulates a form submission process.

Key functionalities include:

  • Displaying company information, mission, and values.
  • Showcasing team members with their roles and bios.
  • Providing a contact form for users to send messages.
  • Displaying contact methods like live chat, phone, and email support.
  • Using `framer-motion` for animations and various UI components (Card, Button, Input, Textarea, Label, Tabs, Badge) for structure and styling.

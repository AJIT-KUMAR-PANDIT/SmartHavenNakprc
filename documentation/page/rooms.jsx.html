Rooms Page (rooms.jsx) Documentation

Overview

This file (`rooms.jsx`) implements the Rooms page of the client application. It allows users to manage rooms and the devices associated with them.

The component uses the `useRooms` hook to fetch and manage room data and the `useDevices` hook to fetch device data. It also utilizes the `useQuery` hook from `@tanstack/react-query` to fetch devices specifically for displaying within room cards.

It includes state for managing room and device modals, selected room/device, and the visibility of device lists within room cards.

Key functionalities include:

  • Displaying a list of rooms.
  • Showing devices associated with each room.
  • Providing options to edit and delete rooms.
  • Allowing toggling of all devices within a room.
  • Displaying device cards within rooms with options to toggle, edit, and delete individual devices.
  • Opening modals for adding/editing rooms and devices.
  • Helper functions (`getRoomIcon`, `getDeviceIcon`, `capitalizeFirstLetter`) for UI presentation.

Logs Page (logs.jsx) Documentation

Overview

The Logs page component (logs.jsx) provides a user interface for viewing and managing system activity logs. It allows users to see a list of events, search and filter logs, and export them in different formats.

Features

  • Fetches and displays activity logs using the useLogs hook.
  • Provides a search input to filter logs by action or message.
  • Allows clearing the search filter.
  • Offers two view modes: List View and Timeline View.
  • Includes an option to export logs in JSON or CSV format.
  • Displays loading, error, and empty states appropriately.

Dependencies

  • useLogs hook for fetching, filtering, and downloading logs.
  • UI components from @/components/ui such as Button, Input, Tabs, Select, etc.
  • Utility function formatDate from @/lib/utils.
  • Icons from lucide-react.
  • Animation from framer-motion.

State Management

The component manages local state for the download format (downloadFormat), active tab (activeTab), and search input value (searchValue). It utilizes the state and functions provided by the useLogs hook for log data, loading status, error handling, filtering, and downloading.

Functionality

  • useEffect hooks are used to load logs on component mount and to debounce the search input for filtering.
  • handleDownload function triggers the log download process using the downloadLogs function from the useLogs hook.
  • Logs are formatted by date for the Timeline View using the getLogsByDate function from the useLogs hook.

Rendering

The component renders a header, search and tab controls, and content based on the loading/error state and the active tab. The List View displays logs in a table, while the Timeline View groups logs by date.

Error and empty states are handled with informative messages and options to retry loading or clear filters.

The component uses framer-motion for fade-in animation on the main container and rotation animation on the loading spinner.

Styling is applied using Tailwind CSS classes, often combined with utility functions like cn.

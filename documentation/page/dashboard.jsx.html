Dashboard Page (dashboard.jsx) Documentation

Overview

This file (`dashboard.jsx`) implements the main dashboard page of the client application. It provides an overview of the smart home system, displaying key statistics like connected devices, active routes, and MQTT connection status. It also features a section for quick device control and a view of dynamic routes.

The component utilizes several hooks, including `useDevices` and `useRoutes`, to fetch and manage data. It also uses `useState` and `useEffect` for local state management and periodic updates (e.g., MQTT status). The UI is built using various custom components like `StatusCard`, `ConnectionStatusCard`, and `DeviceCard`, along with components from a UI library (likely Shadcn UI based on the imports).

Key functionalities include:

  • Displaying counts of online devices and active routes.
  • Showing the current MQTT connection status.
  • Providing a list of devices with controls to toggle, edit, and delete them.
  • Displaying a table of dynamic routes.
  • Opening modals for adding/editing devices.

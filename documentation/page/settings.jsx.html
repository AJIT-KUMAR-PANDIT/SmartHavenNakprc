Settings Page (settings.jsx) Documentation

Overview

The Settings page component (settings.jsx) provides a comprehensive interface for users to configure various aspects of the SmartHaven application, including server connections, MQTT settings, notifications, theme preferences, and advanced options.

Features

  • Load and save application settings.
  • Configure server URL and API key.
  • Configure MQTT broker connection details (URL, port, username, password, client ID).
  • Connect and disconnect from the MQTT broker.
  • Toggle mock data mode for development/testing.
  • Reset application guide and mock data.
  • Synchronize mock data to local database.
  • Configure notification preferences (show notifications, sound, error notifications).
  • Configure theme preferences (dark mode, accent color).
  • Configure advanced settings (log level, log retention, device check interval).
  • Export and import settings to/from a JSON file.
  • User authentication status display and logout functionality.

Dependencies

  • framer-motion for animations.
  • UI components from @/components/ui (Button, Input, Card, Tabs, Switch, Label, Textarea, ThemeToggle).
  • Icons from lucide-react.
  • Hooks: useAuth, useTheme.
  • Context: useDataMode.
  • Utility functions from @/lib/db (getSettings, saveSettings, exportSettings, importSettings, addLog).
  • Utility function downloadAsFile from @/lib/utils.
  • MQTT functions from @/lib/mqtt (initMQTT, disconnect, getConnectionStatus).

State Management

The component manages various state variables including loading and saving status, MQTT connection status, form errors and success messages, confirmation dialog visibility, and the form data itself (settings object). It uses the useState hook for local state and context/hooks for global state (authentication, theme, data mode).

Functionality

  • Settings are loaded on component mount using useEffect and the getSettings function.
  • MQTT connection status is updated periodically using an interval within a useEffect hook.
  • Input and switch changes are handled by updating the local settings state.
  • handleSaveSettings function validates and saves the settings using the saveSettings function.
  • handleConnectMQTT function initializes or disconnects the MQTT connection based on the current status and configured settings.
  • handleExportSettings function exports the current settings using exportSettings and downloads them as a JSON file.
  • handleImportSettings function triggers a file input and imports settings from a selected JSON file using importSettings.
  • handleResetGuide, handleResetMockData, and handleSyncToLocalDb functions interact with the useDataMode context to manage application data and guide state.
  • handleLogout function calls the logout function from the useAuth hook.

Rendering

The component renders different sections for Server, MQTT, Notifications, Theme, and Advanced settings using Tabs. Each section contains relevant input fields, switches, and buttons for configuration. Loading, saving, error, and success states are displayed to the user. A confirmation dialog is shown before resetting mock data.
